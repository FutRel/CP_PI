## Курсовой проект - проектирование и разработка ИС Маркетплейса.
Данный проект является финальной частью дисциплины "Программная инженерия", в результате которого была спроектирована и разработана ИС Маркетплейса в виде мобильного приложения на базе ОС Android на Java.

ИС представляет собой MVP реализацию деятельности маркетплейса, содержащую авторизацию и регистрацию для пользователей (как и покупателей, так и продавцов), а также их личных кабинетов и страницы каталога.

Реализовано: шифрование паролей, CRUD-операции по взаимодействию с базой данных товаров и пользователей, загрузка и хранение изображений в локальной памяти устройства.

Также, все этапы разработки ИС и его проектирования задокументированы и находятся в файле "DOC.pdf", с анализом аналогов, ER-диаграммами различных уровней, спецификацией требований, архитектурой ИС в нотации C4, а также с различными тестами.
